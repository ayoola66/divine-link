# Story 8.4: Export & Share Functionality

**Story ID:** 8.4
**Epic:** 8 - UX/UI Modernization & Platform Expansion
**Priority:** P0 (Must-Have)
**Complexity:** Small
**Estimated Effort:** 6-10 hours
**Phase:** Phase 2 (Week 2)
**Target Version:** v2.0.0

---

## Story Description

Enable operators and pastors to export service scripture lists to PDF, Markdown, or plain text formats, including service metadata, for use in sermon notes, bulletins, or study materials.

---

## User Story

**As a** pastor or church administrator
**I want** to export scripture lists from services
**So that** I can include them in sermon notes, bulletins, or share with the congregation

---

## Business Value

- **Data Portability:** Enables use of Divine Link data in other tools
- **Pastor Value:** Facilitates sermon preparation and review
- **Workflow Integration:** Connects Divine Link to broader church workflows
- **Low-Hanging Fruit:** Low effort, moderate value

**Impact Score:** 2/5 (Nice-to-have, enables broader workflows)

---

## Acceptance Criteria

### Export Formats
- [ ] PDF export with formatted layout
- [ ] Markdown export (plain text with formatting)
- [ ] Plain text export (no formatting)

### Export Content (All Formats)
- [ ] Service metadata: Date, Time, Pastor, Sermon Title
- [ ] Scripture list: Reference + Full verse text + Translation
- [ ] Export timestamp: "Exported on [date/time]"
- [ ] Footer: "Generated by Divine Link v2.0"

### Export UI
- [ ] Export button in Session History view (bottom of session details)
- [ ] Clicking opens menu with 3 options: PDF, Markdown, Text
- [ ] Selecting format opens macOS save dialog
- [ ] Default filename: "Service_YYYY-MM-DD_Pastor.ext"
- [ ] Save to user-selected location

### PDF Format Specifications
- [ ] Page size: Letter (8.5" × 11")
- [ ] Margins: 1" all sides
- [ ] Header: Service metadata (bold, 16pt)
- [ ] Scriptures: Each reference as subheading (14pt, bold)
- [ ] Verse text: Body text (12pt, Georgia serif)
- [ ] Footer: Page numbers, export timestamp

### Markdown Format Specifications
```markdown
# Sunday Morning Service
**Date:** February 18, 2026
**Pastor:** John Smith
**Sermon:** God's Love

---

## John 3:16 (Berean Standard Bible)
For God so loved the world that He gave His one and only Son...

## Romans 8:28 (Berean Standard Bible)
And we know that in all things God works for the good of those...

---

*Exported on February 18, 2026 at 3:45 PM*
*Generated by Divine Link v2.0*
```

### Plain Text Format Specifications
```
SUNDAY MORNING SERVICE
Date: February 18, 2026
Pastor: John Smith
Sermon: God's Love

----------------------------------------

JOHN 3:16 (Berean Standard Bible)
For God so loved the world that He gave His one and only Son...

ROMANS 8:28 (Berean Standard Bible)
And we know that in all things God works for the good of those...

----------------------------------------

Exported on February 18, 2026 at 3:45 PM
Generated by Divine Link v2.0
```

### Share Sheet Integration (macOS)

- [ ] Opens native macOS share sheet
- [ ] Options: Mail, Messages, AirDrop, Save to Files

## Technical Specifications

### Export Service
```swift
class ExportService {
    func exportToPDF(session: ServiceSession) -> URL {
        // Generate PDF using PDFKit
        // Return temporary file URL
    }

    func exportToMarkdown(session: ServiceSession) -> URL {
        // Generate Markdown string
        // Write to temp file, return URL
    }

    func exportToText(session: ServiceSession) -> URL {
        // Generate plain text string
        // Write to temp file, return URL
    }

    private func generateFilename(session: ServiceSession, ext: String) -> String {
        let dateFormatter = DateFormatter()
        dateFormatter.dateFormat = "yyyy-MM-dd"
        let dateString = dateFormatter.string(from: session.date)
        let pastor = session.pastor.replacingOccurrences(of: " ", with: "_")
        return "Service_\(dateString)_\(pastor).\(ext)"
    }
}
```

### PDF Generation (Using PDFKit)
```swift
import PDFKit

func generatePDF(session: ServiceSession) -> Data {
    let pdfMetadata = [
        kCGPDFContextCreator: "Divine Link",
        kCGPDFContextTitle: "Service Scripture Export"
    ]
    let format = UIGraphicsPDFRendererFormat()
    format.documentInfo = pdfMetadata as [String: Any]

    let pageRect = CGRect(x: 0, y: 0, width: 612, height: 792) // Letter size
    let renderer = UIGraphicsPDFRenderer(bounds: pageRect, format: format)

}
```
